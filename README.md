# Place of Serenity

A responsive website for Place of Serenity, built with a modern React and TypeScript frontend.

**[View the live website](https://placeserenity.com/)**

## Project overview

Place of Serenity is a web design and frontend development project featuring a structured landing-page experience. The site includes sections for an introduction, about information, services, facilities, testimonials, and contact details.

This repository is presented as part of my web development portfolio to demonstrate frontend implementation, component-based development, styling, navigation, and interactive page behavior.

## Tech stack

- **React 18** and **TypeScript** — frontend components and type safety
- **Vite** — development and production builds
- **Tailwind CSS** — styling and responsive layouts
- **shadcn/ui and Radix UI** — UI component foundations
- **Framer Motion** — animation tooling
- **React Router** — client-side routing
- **Lucide React** — icons

## Website sections

- Home / hero
- About
- Services
- Facilities
- Testimonials
- Contact

## Run locally

Prerequisites: Node.js and npm.

```bash
git clone https://github.com/Storm-Wind1/place-of-serenity-landing.git
cd place-of-serenity-landing
npm ci
npm run dev
```

Open the local URL printed by Vite.

To create and preview a production build:

```bash
npm run build
npm run preview
```

To run the linter:

```bash
npm run lint
```
